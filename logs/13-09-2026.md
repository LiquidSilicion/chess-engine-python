## 2. Technical Breakdown & Explanations

### 2.1 Chess Engine Architecture
Instead of writing complex rule logic from scratch (which is prone to bugs regarding castling, en passant, etc.), I utilized the `python-chess` library to handle board state and legal move generation. The core AI logic was built around three main components:

1. **Evaluation Function (`evaluation.py` & `utils.py`):** 
   - *Material Count:* Assigns centipawn values to pieces (Pawn=100, Knight=320, Bishop=330, Rook=500, Queen=900, King=20000).
   - *Piece-Square Tables (PST):* Adds positional bonuses. For example, a knight in the center of the board yields a higher score than a knight on the edge, giving the engine basic positional awareness without needing deep search.
2. **Search Algorithm (`search.py`):** 
   - Implemented the **Minimax algorithm** to simulate future game states.
   - Integrated **Alpha-Beta Pruning** to drastically reduce the search space. By maintaining an `alpha` (minimum score the maximizing player is assured of) and `beta` (maximum score the minimizing player is assured of) bounds, the engine stops evaluating branches that cannot possibly affect the final decision.
3. **Engine Interface (`engine.py`):** 
   - Wrapped the search and evaluation logic into a clean `ChessEngine` class to handle game state, move execution, and depth configuration.

### 2.2 Repository & CI/CD Setup

- **Packaging:** Created a `setup.py` and `requirements.txt` to manage dependencies (`python-chess`, `numpy`, `pytest`).

### 2.3 Python Packaging & Path Resolution (Debugging)
**The Issue:** When running `python3 play_vs_engine.py` from inside the `examples/` directory, Python threw a `ModuleNotFoundError: No module named 'src'`. This happens because Python's `sys.path` only includes the directory of the script being executed, not the project root.

**The Solution:** Instead of using "hacky" `sys.path.insert()` workarounds in the scripts, I resolved this by treating the project as an installable Python package. 
- By running `pip3 install -e .` (editable mode) from the project root, the `src` directory is linked to the Python environment. 
- This allows any script in `examples/` or `tests/` to cleanly `import src` regardless of where the script is executed from, which is the industry-standard way to handle local Python project imports.
